1. it replaced the original converted bundle's Jinja chat template with a community-style simplified ChatML template containing a fixed empty `<think>...</think>` block for assistant messages and generation prompts;
2. it added stop token 248046 alongside existing 248044.

The current tool-orchestration regression appeared only once the repaired MCP240 bundle could actually be exercised in Agent. The template replacement is therefore a primary suspect. It can alter role serialization/history/tool-result semantics even though the underlying model weights are unchanged.

The next action is evidence-only inspection: reconstruct the original MCP238 bundle and MCP240 bundle, unpack both with the official LiteRT-LM 0.15 packager, and publish a normalized diff of `LlmMetadataProto.pbtext`, especially `jinja_prompt_template`, stop tokens, and relevant metadata.
